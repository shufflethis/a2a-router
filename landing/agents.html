AGENT INTERFACES / LIVE MVP

One brief.
Three ways to call it.

a2a-router is an order passport MVP for agent-assisted manufacturing. Browser users can keep a self-reported local event history. Agents can read requirements and prepare the same structured draft. These tools do not save an order, submit a request, contact manufacturers or pay.

Browser tools · WebMCP

The home page and this page register these read-only tools through document.modelContext.registerTool. A locally served WebMCP polyfill preserves native support when available. Browser agent access depends on the browser or agent integration; a manifest does not guarantee compatibility with a particular assistant.

Remote MCP

Connect an MCP client to https://www.a2a-router.com/api/mcp using Streamable HTTP. No account is required for read-only brief preparation. Call initialize, then tools/list.

{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": {
    "name": "a2a_router.prepare_manufacturing_brief",
    "arguments": {
      "process": "sheet_metal",
      "description": "Ten brackets matching the buyer-approved drawing; dimensions remain to be confirmed.",
      "material": "Buyer-specified aluminum grade",
      "quantity": 10,
      "country": "US",
      "acceptance": "Buyer checks quantity, critical dimensions against the approved drawing and finish."
    }
  }
}

The other new tool is a2a_router.manufacturing_requirements. Existing status, pledge and bridge tools remain available. Bridge calls can invoke external tools with side effects; get the user's authorization for the actual external action.

REST API

Method & routeAction
GET /api/statusCurrent product status
GET /api/requirements?process=sheet_metalRead process requirements
POST /api/briefPrepare a draft from application/json; form-urlencoded returns an HTML review

Process values: cnc_machining, sheet_metal, additive_manufacturing. Quantity must be an integer from 1 to 100000. Country is a two-letter destination code. Acceptance criteria are required. Optional: tolerance, finish, deadline, drawingUrl. Drawing links are not fetched.

Read the limits

The published signed pledge and Agent Card are unchanged historical bridge metadata and remain self-attested. Read current product status separately. Local order events are entered by the user and verified for hash consistency only. Factory identity, delivery and payment are not independently verified. There is no central production ledger, paid audit, escrow or buyer protection today.

The brief API returns a draft without application-level order storage. Browser form preparation uses the same logic locally. Local passports can be exported and imported; do not put private tokens in drawing links. No tool in this release registers a factory or pays a supplier. Agent Tracking records page paths, referral domains and tool names, duration and result status; the embedded script does not send tool arguments or form values. See data use.
